# Отчет по лабораторной работе №1

## Тема: Элементарные операции с таблицами. Библиотека Pandas

**Цель работы:** Изучение основных возможностей библиотеки Pandas для обработки и анализа табличных данных.

**Задание:**

1. Загрузить датасет `learn_dataset.csv`.
2. Провести первичный анализ структуры данных (типы признаков, пропуски).
3. Выполнить операции фильтрации, сортировки и группировки.
4. Рассчитать новые признаки (индекс массы тела).
5. Проанализировать корреляцию между признаками.
