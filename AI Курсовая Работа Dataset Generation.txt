Mathematical Modeling and Spatial-Economic Analysis: A Benchmark Dataset and Diagnostic Pipeline for Term Projects in Applied Artificial Intelligence
Domain Selection and Pedagogical Rationale
Term projects (курсовые работы) in applied artificial intelligence within Russian higher education require a dataset that acts as a rigorous testing ground for the entire data science lifecycle.1 A typical student project must demonstrate proficiency in several core methodologies: complex data engineering, multivariate data visualization, missing value imputation, spatial and structural anomaly detection, unsupervised clustering, and supervised learning across parametric regression and multi-class classification.1 To determine the optimal domain for these academic requirements, three candidate environments—Healthcare, Retail/E-commerce, and Real Estate—must be systematically evaluated.
The Real Estate domain—specifically modeled after the Moscow housing market—is selected as the superior environment for this course. Unlike abstract clinical or digital interaction logs, real estate transactions are governed by physical constraints and spatial economics. The physical area of an apartment must obey strict inequalities, and its proximity to primary transportation infrastructure directly influences its economic value.6 This structural logic allows students to evaluate model predictions against real-world constraints, helping them identify when a model's outputs violate physical reality.9
For students who wish to use real-world datasets rather than synthetic generation, several high-quality public repositories are directly accessible:
The Moscow Housing Price Dataset (Egor Kainov): Available on Kaggle at https://www.kaggle.com/datasets/egorkainov/moscow-housing-price-dataset. This dataset captures current listings, spatial variables, apartment types, and renovation statuses.7
Sberbank Russian Housing Market Dataset: Available via the official Kaggle competition page at https://www.kaggle.com/competitions/sberbank-russian-housing-market. It provides a highly complex, macroeconomic-linked dataset of Moscow transactions.12
Dataset Architecture and Mathematical Formulation
System Schema and Variable Specifications
The synthetic benchmark dataset, moscow_housing_study.csv, is designed as an uncleaned extract of 2,000 transaction records across Moscow and the Moscow Oblast.7 The dataset features a mix of numeric, categorical, and temporal variables structured to test student data engineering pipelines.1
Python Generation Script for Reproducible Research
The following script programmatically generates moscow_housing_study.csv. The generation algorithm embeds realistic physical dependencies, linear and non-linear interactions, missing data mechanisms, and multi-scale anomalies to test student pre-processing pipelines.
Python
import numpy as np
import pandas as pd

# Set seed for deterministic reproducibility across student environments
np.random.seed(42)
n_samples = 2000

# 1. Generate core independent physical dimensions
full_area = np.random.lognormal(mean=3.9, sigma=0.4, size=n_samples) + 15.0 # Min area ~ 20 sqm
full_area = np.clip(full_area, 18.0, 350.0) # Realistic bounds

# Establish physical constraint: living area ~ 60% of full area with Gaussian noise
living_ratio = np.random.normal(loc=0.6, scale=0.08, size=n_samples)
living_area = full_area * np.clip(living_ratio, 0.35, 0.85)

# Establish physical constraint: kitchen area ~ 15% of full area with Gaussian noise
kitchen_ratio = np.random.normal(loc=0.15, scale=0.03, size=n_samples)
kitchen_area = full_area * np.clip(kitchen_ratio, 0.08, 0.30)

# Generate integer structures
num_rooms = np.zeros(n_samples)
for i in range(n_samples):
    if full_area[i] < 30.0:
        num_rooms[i] = 0 # Studio
    elif full_area[i] < 50.0:
        num_rooms[i] = 1
    elif full_area[i] < 80.0:
        num_rooms[i] = np.random.choice(, p=[0.3, 0.7])
    elif full_area[i] < 120.0:
        num_rooms[i] = np.random.choice(, p=[0.2, 0.8])
    else:
        num_rooms[i] = np.random.choice(, p=[0.3, 0.5, 0.2])

floor = np.random.randint(1, 26, size=n_samples)
max_floors = floor + np.random.randint(0, 15, size=n_samples)

# Spatial metrics
metro_distance_km = np.random.exponential(scale=2.5, size=n_samples)
metro_distance_km = np.clip(metro_distance_km, 0.1, 25.0)

# Categorical allocations
regions = np.random.choice(['Moscow', 'New_Moscow', 'Moscow_Oblast'], size=n_samples, p=[0.55, 0.20, 0.25])
renovations = np.random.choice(, size=n_samples, p=[0.20, 0.45, 0.25, 0.10])
building_types = np.random.choice(, size=n_samples, p=[0.40, 0.35, 0.25])

# Temporal vector: Transaction listings spanning 2024-01-01 to 2026-05-01
start_date = pd.to_datetime('2024-01-01')
end_date = pd.to_datetime('2026-05-01')
time_deltas = np.random.randint(0, int((end_date - start_date).total_seconds()), size=n_samples)
timestamps = start_date + pd.to_timedelta(time_deltas, unit='s')

# 2. Mathematical Price Generation (Base logic + physical interactions)
# Baseline price per square meter in Moscow: ~250,000 RUB
base_m2_price = 250000.0

# Apply regional scaling coefficients
region_coeff = {'Moscow': 1.0, 'New_Moscow': 0.75, 'Moscow_Oblast': 0.55}
r_coeffs = np.array([region_coeff[r] for r in regions])

# Apply renovation scaling coefficients
renovation_coeff = {'None': 0.85, 'Cosmetic': 1.0, 'Euro': 1.18, 'Designer': 1.40}
ren_coeffs = np.array([renovation_coeff[rn] for rn in renovations])

# Apply structural quality coefficients
build_coeff = {'Panel': 0.90, 'Brick': 1.05, 'Monolith': 1.20}
b_coeffs = np.array([build_coeff[b] for b in building_types])

# Proximity premium: Exponential decay of price as distance to metro increases
metro_decay = np.exp(-0.08 * metro_distance_km)

# Compute target regression price with multi-factor multiplicative interactions + Gaussian noise
noise = np.random.normal(loc=1.0, scale=0.12, size=n_samples)
price_rub = (full_area * base_m2_price) * r_coeffs * ren_coeffs * b_coeffs * (0.7 + 0.3 * metro_decay) * noise

# Format prices to realistic integers
price_rub = np.round(price_rub, -4)

# 3. Inject Missing Values (MAR and MCAR) to test pre-processing
mask_living = np.random.rand(n_samples) < 0.10 # 10% MCAR missing
living_area[mask_living] = np.nan

mask_kitchen = np.random.rand(n_samples) < 0.08 # 8% MCAR missing
kitchen_area[mask_kitchen] = np.nan

mask_metro = np.random.rand(n_samples) < 0.05 # 5% MCAR missing
metro_distance_km[mask_metro] = np.nan

# Categorical missingness: 5% of renovations are missing
mask_renovation = np.random.rand(n_samples) < 0.05
renovations_with_nan = renovations.astype(object)
renovations_with_nan[mask_renovation] = np.nan

# 4. Inject Realistic Anomalies and Outliers to test robust scaling and filtering
# Anomaly Type A: Unphysical structural overlap (Living Area > Full Area)
anomaly_idx_a = np.random.choice(n_samples, size=10, replace=False)
for idx in anomaly_idx_a:
    living_area[idx] = full_area[idx] * 1.15  # Impossible physical state

# Anomaly Type B: Extreme luxury estate pricing outliers
anomaly_idx_b = np.random.choice(n_samples, size=5, replace=False)
for idx in anomaly_idx_b:
    price_rub[idx] = price_rub[idx] * 6.5  # Artificial extreme pricing outlier

# Anomaly Type C: Zero-value kitchen area anomalies in high-end properties
anomaly_idx_c = np.random.choice(n_samples, size=8, replace=False)
for idx in anomaly_idx_c:
    kitchen_area[idx] = 0.0

# 5. Define Classification Target: Ordinal Price Segments
# Calculate clean boundaries on original baseline to ensure mathematical modeling capability
q33, q66 = np.percentile(price_rub, [33.3, 66.6])
price_segment = np.where(price_rub <= q33, 'Budget', np.where(price_rub <= q66, 'Standard', 'Premium'))

# 6. Assemble Final Dataframe and Export
dataset = pd.DataFrame({
    'id': np.arange(1, n_samples + 1),
    'timestamp': timestamps,
    'full_area': np.round(full_area, 1),
    'living_area': np.round(living_area, 1),
    'kitchen_area': np.round(kitchen_area, 1),
    'floor': floor,
    'num_rooms': num_rooms.astype(int),
    'metro_distance_km': np.round(metro_distance_km, 3),
    'region': regions,
    'renovation': renovations_with_nan,
    'building_type': building_types,
    'price_rub': price_rub,
    'price_segment': price_segment
})

dataset.to_csv('moscow_housing_study.csv', index=False)

Multi-Scale Analytical Framework and Core Scientific Questions
The designed benchmark dataset supports six scientific questions that target distinct phases of the machine learning pipeline.1 These questions challenge students to look past baseline metrics and analyze the mathematical and spatial relationships in the data.
Temporal Elasticity and Seasonality Analysis
Students analyze how listings and valuations change over the temporal timeline to identify seasonal cycles and inflation. This requires converting the timestamp column into datetime objects, extracting temporal components (year, month, weekday), and performing aggregations.10 Students must distinguish between chronological market growth (such as inflation) and cyclical variations (such as the standard drop in real estate activity during the January holidays).6 This teaches students how to model time-varying signals in cross-sectional structures.
Spatial Price Decay and Distance Decay Functions
Students model the mathematical relationship between distance to the nearest metro station and transaction price across different regions. Proximity to transit infrastructure acts as a primary price driver, but its impact varies by location.6 While central Moscow listings display an exponential price decay as distance increases, outer regions like the Moscow Oblast exhibit a flatter, more linear relationship. This variation exposes the challenges of spatial non-stationarity in linear regression models.
Structural Collinearity and Imputation Robustness
Students assess how collinearity among physical features (full_area, living_area, kitchen_area, and num_rooms) degrades parametric regression models, and evaluate how different imputation strategies affect this collinearity.6 Imputing missing values using simple strategies like the median can distort physical constraints—such as generating a living area that exceeds the total area of the apartment.9 Students must compare these simple approaches with advanced multivariate methods like KNN Imputer to see which best preserves the joint probability distributions of the physical features.
Latent Sub-Market Discovery via Unsupervised Clustering
Students evaluate whether clustering algorithms like K-Means or DBSCAN can discover coherent latent sub-markets that are more useful than official administrative regions.8 Grouping properties by spatial and physical attributes reveals socio-economic clusters, such as "suburban high-density commuter hubs" or "low-density luxury enclaves." Students use the Elbow Method and Silhouette Analysis to evaluate cluster quality, testing whether unsupervised patterns align with real-world real estate categories.
Structural Renovation Elasticity and Probability Boundaries
Students investigate how interior renovation quality affects the probability of a property being classified into the "Premium" price segment, controlling for physical size and region.7 Transforming nominal features into numeric representations allows classification models to calculate class probabilities.1 This analysis reveals whether high-end renovations consistently add value, or if their impact is heavily dependent on the property's geographic location.
Predictive Performance Trade-Offs in Parametric vs. Non-Parametric Modeling
Students compare the performance of linear regression models with advanced non-parametric and gradient boosting frameworks.1 While linear models with regularization are highly interpretable, they often struggle with non-linear relationships, such as the interaction between floor height and price. Conversely, models like Random Forest and Gradient Boosting achieve lower errors but act as black boxes.1 This comparison helps students understand the fundamental trade-off between predictive accuracy and model interpretability.

# Extrapolating and sorting feature importance vector
importances = forest.feature_importances_
importance_series = pd.Series(importances, index=X_train.columns).sort_values(ascending=False)

# Visualizing feature importance
importance_series.plot(kind='bar')
plt.title('Random Forest Feature Importances')
plt.ylabel('Gini Importance')
plt.show()
Pedagogical Objectives and Expected Outcomes
Implementing this machine learning pipeline using the moscow housing dataset helps students build a solid foundation in applied artificial intelligence.1
Students typically find that parametric linear regression models are highly interpretable but struggle to capture complex non-linear relationships. For instance, the premium placed on proximity to a metro station often decreases non-linearly as distance increases—a relationship that OLS models can only capture through manual feature transformations.6 In contrast, non-parametric ensemble models and gradient boosting frameworks handle these non-linearities and interactions automatically, though at the cost of direct interpretability.1
In the classification task, students observe how different algorithms partition the feature space. Simple models like kNN are sensitive to feature scales and outliers, whereas Decision Trees are robust to scaling but prone to high variance and overfitting if left unregularized.
By executing this project, students move past simply calling machine learning libraries. They learn to systematically handle missing data, identify real-world anomalies, manage collinearity, and make informed trade-offs between model accuracy and interpretability.1
