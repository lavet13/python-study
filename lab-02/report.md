### 2. Обработка пропущенных значений

**Метод 1: удаление строк (dropna)**

`dropna()` удаляет все строки с хотя бы одним `NaN`. В результате

**Метод 2: заполнение нулём (fillna)**


`fillna(0)` заменяет все `NaN` константой 0. Для числовых признаков

**Метод 3: заполнение модой (правильный способ)**


Для категориальных признаков корректная стратегия — заполнение наиболее

### 3. Выявление и устранение аномалий

Анализ проводился на подмножестве женщин с ненулевым `capitalgain`
(938 записей). Перед построением `boxplot` отфильтрованы нулевые
значения — в противном случае медиана и квартили равнялись бы нулю,
а диаграмма не несла бы информации об аномалиях.

```python
df_fem = df[(df["sex"] == "Female") & (df["capitalgain"] > 0)].copy()
sns.boxplot(data=df_fem, y="capitalgain")
```

Прямоугольник («ящик») охватывает 50% значений (от 25-й до 75-й
процентили), линия внутри — медиана, «усы» — допустимый диапазон,
точки за усами — выбросы.

**Способ 1: правило трёх сигм**

```python
m, s = df_fem["capitalgain"].mean(), df_fem["capitalgain"].std()
left_1, right_1 = m - 3 * s, m + 3 * s
# Допустимый диапазон: [-1.3; 5.6]
# Осталось строк: 938
```

Метод основан на предположении о нормальном распределении. Значения
за пределами [μ − 3σ; μ + 3σ] считаются аномальными. Поскольку
`capitalgain` закодирован в диапазон от 0 до 4, все 938 значений
попали в допустимый интервал — аномалий не обнаружено.

**Способ 2: метод межквартильного размаха (IQR)**

```python
a, b = df_fem["capitalgain"].quantile(0.25), df_fem["capitalgain"].quantile(0.75)
left_2, right_2 = a - 1.5 * (b - a), b + 1.5 * (b - a)
# 25-я процентиль: 1.0, 75-я процентиль: 3.0
# Допустимый диапазон: [-2.0; 6.0]
# Осталось строк: 938
```

IQR-метод устойчивее к несимметричным распределениям, чем правило
трёх сигм. Допустимый диапазон вычисляется как [Q1 − 1.5·IQR;
Q3 + 1.5·IQR]. Оба метода дали одинаковый результат: аномалий нет.
Это объясняется природой данных — признак закодирован в узкий целочисленный
диапазон 1–4, выбросы в нём математически невозможны.

### 4. Кластеризация методом KMeans

```python
model = KMeans(n_clusters=2, random_state=42, n_init=10)
model.fit(df_clust[["education-num", "hoursperweek"]])
df_clust["label"] = model.labels_
```

KMeans разбивает выборку на `n_clusters` групп, минимизируя суммарное
расстояние от каждой точки до центроида её кластера. Параметр
`random_state` фиксирует начальное положение центроидов — результат
воспроизводим. `n_init=10` означает, что алгоритм запускается 10 раз
с разными начальными центроидами; сохраняется лучший результат.

Кластеризация проводилась по признакам `education-num` и `hoursperweek`
с гипотезой о разделении по полу. Результат сравнивался с реальными
метками вручную:

```python
# Всего мужчин: 32 650.  Верно: 21 806.  Ошибочно: 10 844.
# Всего женщин: 16 192.  Верно:  4 928.  Ошибочно: 11 264.
# Точность: 54.7%
```

Точность кластеризации составила **54,7%** — незначительно выше
случайного угадывания (50%). Это объясняется тем, что средние
значения выбранных признаков у мужчин и женщин практически совпадают:
`education-num` — 10,09 и 10,04 соответственно, `hoursperweek` —
2,10 и 1,65. Алгоритм сформировал кластеры, но они разделяют
выборку по количеству рабочих часов, а не по полу.
