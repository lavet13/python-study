LabelEncoder присваивает каждому уникальному значению целое число
в алфавитном порядке. Проблема: модель может интерпретировать числа
как порядковые (`White=4 > Black=2`), что некорректно для номинальных
категорий.

### 4. One-Hot Encoding

```python
df_ohe = pd.get_dummies(df[["sex", "hoursperweek"]])
df_ohe2 = pd.get_dummies(df[["sex", "hoursperweek"]], drop_first=True)
```

```
--- Результат get_dummies (первые 5 строк) ---
   hoursperweek  sex_Female  sex_Male
0             2       False      True
1             0       False      True
2             2       False      True
3             2       False      True
4             2        True     False
Столбцы: ['hoursperweek', 'sex_Female', 'sex_Male']

--- После drop_first=True ---
   hoursperweek  sex_Male
0             2      True
1             0      True
Столбцы: ['hoursperweek', 'sex_Male']
```

`get_dummies()` создаёт отдельный бинарный столбец для каждого
уникального значения категориального признака. `drop_first=True`
удаляет первый столбец каждой группы — он избыточен, поскольку
при `sex_Male=0` значение `sex_Female` гарантированно равно 1.

**Предсказание с One-Hot признаком**

```python
df_full = pd.get_dummies(df[["hoursperweek","education-num","age","capitalgain","sex"]],
                         columns=["sex"], drop_first=True)
tree = DecisionTreeClassifier(max_depth=3, random_state=42)
```

```

```

Точность совпадает с результатом из Lab 3 (68.52%) — это ожидаемо,
поскольку одна бинарная переменная после `get_dummies` эквивалентна
`LabelEncoder` для двухзначного признака. Разница между методами
становится принципиальной при трёх и более категориях.

**Выводы:**

В ходе лабораторной работы реализованы продвинутые методы машинного
обучения. Дерево регрессии достигло MAE = 0.8533 и не улучшилось при
ограничении глубины — данные уже не требовали более глубоких разбиений.
Случайный лес (68.38%) и градиентный бустинг (68.77%) показали
сопоставимые результаты; оба метода превзошли SGDClassifier из Lab 3
по метрике recall для класса Female. Анализ важности признаков
выявил неожиданную доминирующую роль `fnlwgt` при предсказании
`education`. One-Hot Encoding и LabelEncoder дали идентичные результаты
для бинарного признака; для многозначных категорий OHE предпочтительнее,
поскольку не вводит ложный порядок между значениями.
